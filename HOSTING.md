# Хостинг бота 24/7 бесплатно, без карты

Бот: **@CatcherUsernamebot**

Карту не просят только на Render. Всё для него уже готово: `keepalive.py`,
`render.yaml`, токен вынесен из кода.

## 1. Залить код на GitHub

Репозиторий должен быть **приватным** - в нём картинки и логика проекта.

Токен в репозиторий не попадёт: он лежит в `token.txt`, который прописан
в `.gitignore`.

## 2. Создать сервис на Render

1. render.com, регистрация через GitHub - карта не нужна
2. New -> Web Service, выбрать репозиторий
3. Runtime: Python 3
4. Build Command: оставить пустым (зависимостей нет)
5. Start Command: `python bot.py`
6. Instance Type: **Free**

## 3. Передать токен

В настройках сервиса: Environment -> Add Environment Variable

- Key: `BOT_TOKEN`
- Value: токен из `token.txt`

Сохранить, сервис перезапустится сам.

## 4. Не дать сервису уснуть

Render усыпляет бесплатный сервис после 15 минут без входящих запросов.
Поэтому бот поднимает пустую страничку на порту, которую надо пинговать.

1. Взять адрес сервиса, вида `https://catcher-username-bot.onrender.com`
2. Завести бесплатный монитор на uptimerobot.com (карта тоже не нужна)
3. Тип HTTP(s), интервал **10 минут**, адрес сервиса

Открой адрес в браузере - должно быть написано `bot is alive`.

## 5. Выключить локальный бот

Закрой окно "Username Bot" на компьютере. Два экземпляра на одном токене
перехватывают апдейты друг у друга, и бот начнёт отвечать через раз.

## Что нужно знать про бесплатный Render

- **750 часов в месяц на весь аккаунт.** В месяце из 31 дня нужно 744,
  то есть один сервис круглосуточно влезает с запасом в 6 часов. Второй
  бесплатный сервис заводить нельзя - часы общие
- **Перезапуски.** Render может перезагружать бесплатные сервисы когда
  угодно без предупреждения. Это минута-полторы недоступности
- **Диск стирается при перезапуске.** Настройки пользователей из
  `state.json` слетают на умолчания. Кэш картинок `images.json` лежит
  в репозитории, поэтому переживает перезапуск
- **Трафика 100 ГБ в месяц** - боту хватает с огромным запасом
- Без карты при превышении лимитов сервис просто приостановят
  до следующего месяца, а не спишут деньги

## Если понадобится без перезапусков

Oracle Cloud Always Free - настоящая виртуалка навсегда, без лимита часов
и стирания диска. Но там карту просят для верификации (холд около евро,
не списание). Шейп `VM.Standard.E2.1.Micro`, регион Frankfurt, Ubuntu 22.04.

Автозапуск через systemd, `/etc/systemd/system/tgbot.service`:

```ini
[Unit]
Description=Telegram username bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/bot
Environment=BOT_TOKEN=сюда_токен
ExecStart=/usr/bin/python3 /home/ubuntu/bot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now tgbot
journalctl -u tgbot -f
```
